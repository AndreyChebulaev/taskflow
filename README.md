# TaskFlow — приложение для управления задачами

Учебный проект по дисциплине «Разработка мобильных приложений»
(Тюменский индустриальный университет, группа РПСб-23-1, 2026).

Мобильное To-Do приложение для личных задач: быстрое добавление, категории,
дедлайны, приоритеты, повторяющиеся задачи, календарь и push-напоминания.

## Возможности

- Регистрация, вход и восстановление пароля (Supabase Auth)
- Задачи: создание, редактирование, удаление, отметка выполнения
- Три уровня приоритета с цветовой маркировкой, сортировка и фильтры
- Повторяющиеся задачи (день / неделя / месяц): после выполнения создаётся следующая
- Категории с выбором цвета
- Календарь на месяц с отметками дней, где есть задачи
- Напоминания: локальные push-уведомления перед дедлайном
- Профиль со статистикой, настройки, светлая и тёмная тема

## Технологии

| Слой | Технология |
|---|---|
| Клиент | Flutter (Dart), Provider |
| Сервер | Supabase: PostgreSQL, Auth, Row Level Security |
| Уведомления | flutter_local_notifications |
| Дизайн | Figma |

## Структура

```
lib/
  main.dart            — запуск, тема, выбор экрана по сессии
  config.dart          — адрес и публичный ключ Supabase
  theme.dart           — цвета и светлая/тёмная тема
  models/              — модели Task, TaskCategory
  data/                — репозитории (запросы к Supabase)
  state/               — состояние задач и настроек (ChangeNotifier)
  services/            — уведомления
  screens/             — экраны приложения
  widgets/             — общие виджеты
test/                  — модульные тесты
```

## База данных

Таблицы `profiles`, `categories`, `tasks`, `reminders`. Для всех таблиц включён
Row Level Security: пользователь видит и изменяет только свои данные.
При регистрации триггер создаёт профиль и три категории по умолчанию.
Полная схема (таблицы, ограничения, индексы, политики RLS, триггер) —
в файле [`supabase/schema.sql`](supabase/schema.sql).

## Запуск

```
flutter pub get
flutter test
flutter run
```

Требуется Flutter 3.38+ и Android 8.0+.

> Ключ в `lib/config.dart` — публичный (publishable): доступ к данным
> ограничивают политики RLS. Секретный ключ `service_role` в проекте не хранится.
